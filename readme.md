# 🎰 Streamlit 로또 번호 생성기

Python과 Streamlit을 활용하여 실제 로또 공 색상과 함께 번호를 추천받을 수 있는 웹 애플리케이션입니다.

---

## 🛠 주요 기능 및 특징
- **랜덤 번호 추출**: `1 ~ 45` 사이의 숫자 중 중복 없는 `6개`의 번호를 랜덤으로 추출하여 오름차순으로 정렬합니다.
- **기록 유지 (최대 5개)**: 버튼을 계속 누르면 최대 5개 세트까지 화면에 누적되어 표시됩니다. (최신순 정렬)
- **로또 공 색상 구현**: 실제 로또 추첨 기계의 공 색상 규칙에 맞춰 시각적으로 예쁘게 표현됩니다.
  - `1 ~ 10`: 노란색
  - `11 ~ 20`: 파란색
  - `21 ~ 30`: 빨간색
  - `31 ~ 40`: 회색
  - `41 ~ 45`: 초록색
